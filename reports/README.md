# Credit Card Fraud Detection project report

Open [Credit_Card_Fraud_Detection_Original_Format.docx](Credit_Card_Fraud_Detection_Original_Format.docx) in Word. This corrected report directly uses `NewsLens ML.docx`, preserving its original college branding, fonts, styles, margins, tables, numbering and footer. Student names/enrollment numbers and the project-guide fields are blank. The original institution, department, degree and academic-year text is retained. If editing changes pagination, select the document and press **F9** to update page-reference fields.

The report documents the saved project run: dataset audit, method, validation comparisons, selected model and threshold, held-out test metrics, Streamlit interface, verification, limitations, references, and the weekly plan. Project figures come from `figures/`; browser screenshots are in `reports/assets/`. Word measured 33 pages. `template_preservation.json` records checks of the original paragraph formatting and unchanged branding/style resources.

The template-preserving report can be regenerated with `python reports/fill_original_template.py` using the reference document in the Downloads folder and the project's saved outputs. The older `build_report.py` generates the initial redesigned version and should not be used for the corrected report.
